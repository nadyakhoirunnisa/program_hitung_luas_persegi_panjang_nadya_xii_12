B. JUDUL PROGRAM

Program Hitung Luas Persegi Panjang

C. DESKRIPSI MASALAH

Program ini untuk menyelesaikan permasalahan menghitung luas persegi panjang

D. TUJUAN PROGRAM

Untuk membuat program menghitung luas persegi panjang

E. ANALISIS INPUT, PROSES, DAN OUTPUT

1. INPUT:
   L,P,l integer
   P = panjang, diinputkan oleh pengguna
   l = lebar, diinputkan oleh pengguna

2. PROSES:
   Rumus luas persegi panjang L = P*l

3. OUTPUT:
   Hasil luas persegi panjang yang didapat dari L = P*l

F. ALGORITMA / PSEUDOCODE

MULAI

   1. Deklarasi variabel L,P,l
   2. Masukkan nilai P dan l oleh pengguna.
   3. Lakukan proses perhitungan L = P*l.
   4. Tampilkan hasil (OUTPUT) luas persegi panjang
   

SELESAI

Catatan:
- Gunakan bahasa yang jelas dan mudah dipahami.
- Setiap langkah harus berurutan dan logis.
- Sesuaikan algoritma dengan permasalahan program.
- Tidak semua program harus menggunakan
  percabangan dan perulangan.

G. KETERANGAN

dan bagaimana algoritma menyelesaikan masalah.
